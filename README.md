Supports MP4, MKV, MOV, AVI, WMV, FLV, WEBM, M4V
Choose merge order by filename or modification time

Run:
python vid.py

Then:
Enter the absolute path of the video folder.
Review the video information and resolution statistics.
Choose the merge order.
Confirm the merge.
The merged video will be saved as output.mp4 in the source folder.

No video re-encoding is performed, so merging is extremely fast.
